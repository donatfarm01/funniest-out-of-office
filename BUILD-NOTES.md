Build notes — The Funniest Out-of-Office

The entry is a single program, main.ts, that writes one line of out-of-office
auto-reply text to the output file the judge reads. The line is 133 characters
long, inside the 140 character limit, and it is one line with no link and no
second line.

The joke turns on a simple idea: the auto-reply itself has taken over the
inbox. The first draft said the auto-reply was doing the job better than the
human and asked the reader not to tell the manager. That version leaned on a
familiar office joke, so it was revised. The final line keeps the same setup
but replaces the punchline with a three-way comparison, faster than me,
cheaper than me, and then the kicker that nobody has noticed the human is
gone. The twist is that the entry itself is an auto-reply, so the joke is
about the very thing the reader is reading, and every word in the line earns
its place: the date sets the scene, the comparison builds the joke, and the
last clause lands it.

The repository holds the program, a readme with the bounty badges, and the
MIT license. The program was run locally and produced exactly the intended
line, verified by character count and hash.
